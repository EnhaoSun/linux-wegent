# Linux Wegent — 微信工作助手 MVP

> 状态：从零开始 · 2026-11-01 · 全部文档使用中文

## 产品目标
只读取用户明确授权的微信工作会话，识别重要消息、未完成事项和进度变化。**不自动发消息，不读取微信数据库，不解密，不注入或 Hook 微信进程。**

## MVP 范围
1. 用户从可见会话列表中选择关注的聊天（首版可手动登记会话）。
2. Linux 图形桌面通过 AT-SPI 探索会话列表、消息区域及时间/发送者信息。
3. 只针对选中会话读取可见消息；先人工触发，稳定后再做低频增量检查。
4. 本地 SQLite 保存消息、采集证据、去重键、游标与采集健康状态。
5. 从消息提取重要事项、负责人、截止时间和状态变化；保留原文来源。
6. 提供待处理、等待他人、阻塞、已完成及每日摘要；重要结论可人工确认。

## 明确不做
全量聊天历史导入、所有会话扫描、自动回复、消息发送、数据库解密、进程注入、绕过微信风控、多租户云服务、ERP/CRM 集成。

## 关键原则
- 采集范围由用户控制，默认不采集任何会话。
- AT-SPI 可用性是**待验证假设**，不是已实现功能。
- 不能把“没有发现新消息”当成“确认没有新消息”；应显示采集时间与完整性状态。
- 原始聊天仅本地保存；模型调用默认使用脱敏或合成测试数据。
- 未经用户逐项确认，不清理旧资源、不购买服务器、不执行不可逆操作。
