# 环境准备与责任分工（用户 / Pi Agent）

更新：2026-11-01

## 0. 决策
首选：现有 Apple Silicon Mac 上运行 ARM64 Ubuntu Desktop 虚拟机（例如 UTM 或 Parallels）；若 Linux 微信 ARM64 版本不可用或 AT-SPI 行为不符，先验证架构兼容性，再决定是否采用 x86_64 Linux 实机/云桌面。
**现在不购买云服务器。** 普通无图形桌面的 VPS 无法直接满足 AT-SPI 测试。
Pi 是开发/部署 Agent；不需要把 Pi 安装进微信，也不需要把 Pi 作为 Collector 进程。Pi 可以通过 SSH 连接测试机，在图形会话中运行由它编写的测试程序。

## 1. 你需要亲自完成
- [ ] 选择本地 VM（推荐）或已有 Linux Desktop 机器；告知 Pi CPU 架构、系统版本、VM 软件。
- [ ] 在 VM 安装 Ubuntu Desktop 并完成首次图形登录；创建普通用户。
- [ ] 从可信官方来源安装与你的架构兼容的 Linux 微信；亲自扫码登录。不要把密码、二维码、聊天内容发给 Pi。
- [ ] 在系统中允许所需的辅助功能/桌面访问；明确只允许测试选中的工作会话。
- [ ] 准备 1 个测试会话，最好先用自己控制的测试账号/测试群或脱敏样本；不要用敏感客户群直接测试。
- [ ] 如需要远程开发，批准 SSH 连接方式和密钥授权；绝不在仓库提交密钥或凭证。
- [ ] 运行 Pi 给出的验收命令，观察微信是否异常、是否出现账号安全提示；异常立即停止。
- [ ] 决定是否允许使用外部 LLM 处理聊天内容；默认不允许。
- [ ] 在 P0 验收通过之前，不采购 VPS，不配置公网暴露端口。

## 2. Pi Agent 负责完成
- [ ] 读取本仓库 README 与两份 docs；先输出环境检测结果和执行计划。
- [ ] 检测架构、桌面会话类型（X11/Wayland）、DBus session、微信版本、AT-SPI 可达性。
- [ ] 选择最小依赖并安装：Python 3、venv、git、python3-gi、gir1.2-atspi-2.0、at-spi2-core、sqlite3；实际包名按发行版核对。
- [ ] 先写只读 AT-SPI 探测脚本，列出应用控件树结构并默认脱敏；不读取未授权聊天内容。
- [ ] 生成 P0 可行性报告：截图/结构信息（脱敏）、可读字段、缺失字段、风险、Go/No-Go。
- [ ] P0 通过后实现会话白名单、单次采集、SQLite 存储、去重和采集状态。
- [ ] 编写模拟消息与测试，覆盖重名会话、重复文本、缺失时间、重启、漏读和状态变化。
- [ ] 只有 P1 验收通过后再实现增量与事项引擎。
- [ ] 每阶段提交代码、中文文档、运行说明和测试报告；不跳阶段。

## 3. 推荐安装清单
| 组件 | 用途 | 安装者 | 时机 |
| --- | --- | --- | --- |
| Ubuntu Desktop ARM64 | GUI 测试环境 | 你 | P0 前 |
| Linux 微信（官方、架构兼容） | 被测应用 | 你 | P0 前 |
| SSH Server（可选） | Pi 远程执行 | Pi 配置，你授权 | P0 |
| Python 3 + venv | Collector 运行时 | Pi | P0 |
| PyGObject / AT-SPI / DBus | 辅助功能控件树 | Pi | P0 |
| SQLite | 本地数据存储 | Pi | P1 |
| 本地 Web UI | 会话选择、Inbox | Pi | P2–P4 |
| LLM Provider | 事项理解 | Pi 接入，你批准数据使用 | P3 |
| Docker / PostgreSQL / Redis / Kubernetes | 暂不需要 | 无 | 不安装 |
| 云 Linux 服务器 | 暂不需要 | 无 | 不购买 |

## 4. Pi 执行规则
1. 先检查环境再安装，禁止无目的批量安装。
2. 未经批准，不修改微信安装包、不访问微信数据库、不注入/Hook、不读取进程内存。
3. 未经批准，不开启公网访问、不上传原始聊天、不申请云资源、不自动发消息。
4. 任何 UI 自动操作均限于白名单会话，默认单次手动触发、可停止。
5. 不允许把“控件树可访问”直接报告为“消息采集成功”。
6. 每个阶段必须输出：已验证事实、尚未验证假设、失败案例、下一步和用户需要做的动作。

## 5. 交给 Pi 的第一条任务
请先阅读 README.md、docs/MVP-PLAN.md、docs/SETUP-AND-OWNERSHIP.md。
当前只执行 P0：检查 Ubuntu Desktop、微信、DBus 和 AT-SPI 环境；准备最小依赖与只读探测脚本；给出脱敏控件树及可行性报告。不要做 P1–P4，不要访问未授权会话，不要进行数据库解密/内存读取/Hook，不要自动发送消息。如果尚未有 VM 或微信未登录，先输出用户操作清单并等待，不要自行购买云资源。
